# ELITE 11 — Premium Cricket Website
## Professional Multi-Page HTML/CSS/JS Project

### 📁 Project Structure
```
elite11/
├── index.html       ← Main website (all sections)
├── style.css        ← Full stylesheet (Nike-inspired dark theme)
├── app.js           ← Interactive JavaScript (all features)
└── README.md        ← This file
```

### 🚀 How to Run in VS Code
1. Open the `elite11` folder in VS Code
2. Install the **Live Server** extension (if not installed)
3. Right-click `index.html` → **Open with Live Server**
4. The site opens at `http://127.0.0.1:5500`

### 🎨 Design Style
- **Theme**: Dark Navy/Black + Neon Green — Nike Sports Aesthetic
- **Fonts**: Bebas Neue (display), Barlow Condensed (UI), Barlow (body)
- **Icons**: Font Awesome 6.5

### 🛠 Tech Stack (Frontend)
- Pure HTML5, CSS3, Vanilla JavaScript
- No build tools required — open directly in browser
- Google Fonts + Font Awesome via CDN

### 📱 Responsive Breakpoints
- Desktop: 1300px+
- Tablet: 768px–1100px
- Mobile: < 768px
